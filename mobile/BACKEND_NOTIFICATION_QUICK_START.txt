═══════════════════════════════════════════════════════════════════════════════
    BACKEND NOTIFICATION IMPLEMENTATION - QUICK START
═══════════════════════════════════════════════════════════════════════════════

This is a simplified guide for backend developers to quickly implement
notifications for the FanZone mobile app.

═══════════════════════════════════════════════════════════════════════════════
STEP 1: Get Firebase Service Account Key (5 minutes)
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://console.firebase.google.com
2. Select your FanZone project
3. Click gear icon → Project settings
4. Go to "Service accounts" tab
5. Click "Generate new private key"
6. Download the JSON file
7. Save it as: backend/config/serviceAccountKey.json
8. Add to .gitignore: serviceAccountKey.json

═══════════════════════════════════════════════════════════════════════════════
STEP 2: Install Firebase Admin SDK (2 minutes)
═══════════════════════════════════════════════════════════════════════════════

Node.js:
npm install firebase-admin

Python:
pip install firebase-admin

Java:
Add to pom.xml or build.gradle

═══════════════════════════════════════════════════════════════════════════════
STEP 3: Initialize Firebase (5 minutes)
═══════════════════════════════════════════════════════════════════════════════

Node.js Example:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
const admin = require('firebase-admin');
const serviceAccount = require('./config/serviceAccountKey.json');

admin.initializeApp({
  credential: admin.credential.cert(serviceAccount)
});

const messaging = admin.messaging();

Python Example:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
import firebase_admin
from firebase_admin import credentials, messaging

cred = credentials.Certificate('config/serviceAccountKey.json')
firebase_admin.initialize_app(cred)

═══════════════════════════════════════════════════════════════════════════════
STEP 4: Create API Endpoint to Register FCM Tokens (10 minutes)
═══════════════════════════════════════════════════════════════════════════════

Endpoint: POST /api/users/fcm-token

Request Body:
{
  "user_id": "local_user",
  "fcm_token": "eXaMpLeToKeN123...",
  "platform": "android"
}

Database Schema (MongoDB):
{
  user_id: String,
  fcm_token: String,
  platform: String,
  created_at: Date,
  is_active: Boolean
}

Database Schema (SQL):
CREATE TABLE fcm_tokens (
  id INT PRIMARY KEY AUTO_INCREMENT,
  user_id VARCHAR(255),
  fcm_token TEXT,
  platform VARCHAR(20),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  is_active BOOLEAN DEFAULT TRUE
);

═══════════════════════════════════════════════════════════════════════════════
STEP 5: Send Notifications (15 minutes)
═══════════════════════════════════════════════════════════════════════════════

OPTION A: Send to Topic (Recommended)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Node.js:
const message = {
  topic: 'all_news',
  notification: {
    title: 'Breaking News!',
    body: 'Arsenal signs new striker'
  },
  data: {
    type: 'news',
    id: '123'
  }
};

messaging.send(message)
  .then(response => console.log('Sent:', response))
  .catch(error => console.error('Error:', error));

Python:
message = messaging.Message(
    topic='all_news',
    notification=messaging.Notification(
        title='Breaking News!',
        body='Arsenal signs new striker'
    ),
    data={
        'type': 'news',
        'id': '123'
    }
)

response = messaging.send(message)
print('Sent:', response)

OPTION B: Send to Specific Device
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Replace 'topic' with 'token' and provide the FCM token

═══════════════════════════════════════════════════════════════════════════════
STEP 6: Trigger Notifications When Content is Published (20 minutes)
═══════════════════════════════════════════════════════════════════════════════

WHEN: New news article is created
SEND TO: 
  - Topic: all_news (all users)
  - Topic: club_{club_id} (if club-specific)

WHEN: New highlight video is uploaded
SEND TO:
  - Topic: all_news (all users)
  - Topic: club_{club_id} for each club in the match

Example Integration:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// After creating news article
async function createNews(newsData) {
  // Save to database
  const news = await News.create(newsData);
  
  // Send notification
  await messaging.send({
    topic: 'all_news',
    notification: {
      title: news.title.en,
      body: news.body.en.substring(0, 100)
    },
    data: {
      type: 'news',
      id: news._id.toString()
    }
  });
  
  // If club-specific
  if (news.club_id) {
    await messaging.send({
      topic: `club_${news.club_id}`,
      notification: {
        title: news.title.en,
        body: news.body.en.substring(0, 100)
      },
      data: {
        type: 'news',
        id: news._id.toString(),
        club_id: news.club_id
      }
    });
  }
  
  return news;
}

═══════════════════════════════════════════════════════════════════════════════
TOPICS USED BY THE APP
═══════════════════════════════════════════════════════════════════════════════

all_news
  - All users are subscribed
  - Use for general news and highlights

club_{club_id}
  - Users subscribed to their favorite club
  - Example: club_507f1f77bcf86cd799439012
  - Use for club-specific content

═══════════════════════════════════════════════════════════════════════════════
NOTIFICATION DATA PAYLOAD
═══════════════════════════════════════════════════════════════════════════════

Always include these fields in the 'data' object:

type: 'news' | 'highlight' | 'match_reminder'
id: Content ID (for navigation in app)
club_id: (optional) Club ID if club-specific

Example:
{
  "type": "news",
  "id": "507f1f77bcf86cd799439012",
  "club_id": "507f1f77bcf86cd799439013",
  "category": "transfers"
}

COMMON ERRORS & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

ERROR: "Service account key not found"
SOLUTION: Check file path to serviceAccountKey.json

ERROR: "Invalid token"
SOLUTION: Token may have expired, app needs to re-register

ERROR: "Topic not found"
SOLUTION: Topic names are case-sensitive, check spelling

ERROR: "Permission denied"
SOLUTION: Check Firebase project permissions
