    TESTING MOBILE APP WITH BACKEND NOTIFICATIONS
═══════════════════════════════════════════════════════════════════════════════

Quick guide to test the complete notification flow with your backend.

═══════════════════════════════════════════════════════════════════════════════
STEP 1: START THE MOBILE APP (2 minutes)
═══════════════════════════════════════════════════════════════════════════════

1. Connect your Android device via USB
2. Run the app:
   flutter run

3. Watch the console for these logs:
   📱 FCM Token: eXaMpLeToKeN123...
   ✅ Subscribed to topic: all_users
   ✅ Subscribed to topic: club_507f1f77bcf86cd799439011

4. Copy the FCM token (you might need it for testing)

═══════════════════════════════════════════════════════════════════════════════
STEP 2: SELECT A CLUB IN THE APP (1 minute)
═══════════════════════════════════════════════════════════════════════════════

1. If first time, select language (English/አማርኛ/Afaan Oromo)
2. Select your favorite club (e.g., Arsenal FC)
3. App will subscribe to that club's topic automatically

═══════════════════════════════════════════════════════════════════════════════
STEP 3: CREATE NEWS VIA BACKEND (3 minutes)
═══════════════════════════════════════════════════════════════════════════════

Use your backend admin API to create news:

POST http://your-backend-url/api/admin/content
Headers:
  Authorization: Bearer <your_admin_token>
  Content-Type: application/json

Body:
{
  "title": {
    "en": "Test News - Arsenal Victory",
    "am": "የሙከራ ዜና - የአርሰናል ድል",
    "om": "Oduu Yaalii - Injifannoo Arsenal"
  },
  "body": {
    "en": "Arsenal wins 3-0 against Chelsea in a dominant performance",
    "am": "አርሰናል ቼልሲን በ3-0 በጠንካራ አፈጻጸም አሸንፏል",
    "om": "Arsenal Chelsea 3-0 tiin raawwii cimaa ta'een mo'ateera"
  },
  "image_url": "https://example.com/arsenal-win.jpg",
  "category": "match_result",
  "club_id": "507f1f77bcf86cd799439011"
}

Expected Result:
- Backend sends notification to topic: club_507f1f77bcf86cd799439011
- Your mobile device receives notification
- Notification title: "New news from Arsenal FC"
- Notification body: "Test News - Arsenal Victory"

═══════════════════════════════════════════════════════════════════════════════
STEP 4: VERIFY NOTIFICATION ON DEVICE (1 minute)
═══════════════════════════════════════════════════════════════════════════════

CHECK 1: App in Foreground
- Notification appears at top of screen
- Console shows: 📬 Foreground message: New news from Arsenal FC
- Console shows: 📬 Data: {type: news, content_id: xxx, ...}

CHECK 2: App in Background
- Press home button
- Create another news via backend
- Notification appears in notification tray
- Tap notification → App opens
- Console shows: 📱 Notification tapped: New news from Arsenal FC

CHECK 3: App Closed
- Swipe away the app
- Create another news via backend
- Notification appears in notification tray
- Tap notification → App launches
- Console shows: 📱 Notification tapped: New news from Arsenal FC

═══════════════════════════════════════════════════════════════════════════════
STEP 5: TEST HIGHLIGHT NOTIFICATION (3 minutes)
═══════════════════════════════════════════════════════════════════════════════

Create highlight via backend:

POST http://your-backend-url/api/admin/highlights
Headers:
  Authorization: Bearer <your_admin_token>
  Content-Type: application/json

Body:
{
  "match_title": "Arsenal vs Chelsea - Full Match Highlights",
  "youtube_url": "https://youtube.com/watch?v=test123",
  "club_ids": [
    "507f1f77bcf86cd799439011",
    "507f1f77bcf86cd799439012"
  ]
}

Expected Result:
- Backend sends notification to both club topics
- Your device receives notification (if subscribed to Arsenal)
- Notification title: "New Match Highlight"
- Notification body: "Arsenal vs Chelsea - Full Match Highlights"

COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

ISSUE: No notification received
SOLUTION:
1. Check backend logs - was notification sent?
2. Check console - is app subscribed to topic?
3. Verify club_id matches between backend and mobile
4. Check device internet connection
5. Wait 30 seconds - notifications may be delayed

ISSUE: Notification received but no data
SOLUTION:
1. Check backend sends data payload
2. Verify data keys: type, content_id, highlight_id, club_id
3. Check console logs for data extraction

ISSUE: Wrong club receives notification
SOLUTION:
1. Verify club_id in backend request
2. Check topic subscription in mobile app
3. Ensure topic format is: club_{club_id}

ISSUE: Notification tap doesn't work
SOLUTION:
1. Check navigator key is set in main.dart
2. Verify _handleNotificationTap() is called
3. Check console logs for errors

═══════════════════════════════════════════════════════════════════════════════
BACKEND ADMIN API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

Create News:
POST /api/admin/content
- Sends notification to club topic
- Topic: club_{club_id}

Create Highlight:
POST /api/admin/highlights
- Sends notification to all involved club topics
- Topics: club_{club_id} for each club in club_ids array

═══════════════════════════════════════════════════════════════════════════════
TOPICS USED
═══════════════════════════════════════════════════════════════════════════════

all_users
- General notifications to all users
- Mobile app subscribes automatically

club_{club_id}
- Club-specific notifications
- Example: club_507f1f77bcf86cd799439011 (Arsenal FC)
- Mobile app subscribes when user selects favorite club
