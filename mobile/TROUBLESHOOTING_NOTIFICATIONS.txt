STEP 8: COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

ISSUE 1: Club IDs don't match
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SOLUTION:
1. Check mobile app logs for subscribed topic
2. Use the EXACT same club_id in your highlight creation
3. Example: If app shows "club_507f1f77bcf86cd799439011"
   Then use "507f1f77bcf86cd799439011" in club_ids array

ISSUE 2: Backend not sending notifications
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SOLUTION:
1. Check backend logs for FCM errors
2. Verify service account key exists
3. Check Firebase project is active
4. Restart backend server

ISSUE 3: Firebase not initialized
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SOLUTION:
1. Check google-services.json in android/app/
2. Verify package name matches: com.example.fanzone
3. Run: flutter clean && flutter run

ISSUE 4: Notifications disabled on device
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SOLUTION:
1. Settings → Apps → FanZone → Notifications
2. Enable all notification categories
3. Restart app

ISSUE 5: Wrong Firebase project
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SOLUTION:
1. Check google-services.json project_id
2. Check backend service account key project_id
3. Both must match!
