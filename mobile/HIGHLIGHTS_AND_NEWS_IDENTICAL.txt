═══════════════════════════════════════════════════════════════
  HIGHLIGHTS & NEWS - IDENTICAL FUNCTIONALITY
═══════════════════════════════════════════════════════════════

GOOD NEWS: Both highlights and news already have the SAME
call-to-action system implemented!

═══════════════════════════════════════════════════════════════
  HOW IT WORKS
═══════════════════════════════════════════════════════════════

BOTH types create 3 action buttons:
  1. Left (from backend) - Primary action
  2. Middle (automatic) - Save for later
  3. Right (from backend) - Secondary action

═══════════════════════════════════════════════════════════════
  HIGHLIGHT NOTIFICATION
═══════════════════════════════════════════════════════════════

PAYLOAD:
{
  "notification": {
    "title": "New Match Highlight",
    "body": "NEWCASTLE 2-3 EVERTON"
  },
  "data": {
    "type": "highlight",
    "highlight_id": "...",
    "image_url": "...",
    "action_left": "watch",
    "action_left_label": "Watch",
    "action_right": "dismiss",
    "action_right_label": "Dismiss"
  }
}

RESULT:
  [Watch] [Watch Later] [Dismiss]

═══════════════════════════════════════════════════════════════
  NEWS NOTIFICATION
═══════════════════════════════════════════════════════════════

PAYLOAD:

    "title": "New news from Arsenal FC",
    "body": "Big Win Today"
  },
  "data": {
    "type": "news",
    "content_id": "...",
    "image_url": "...",
    "action_left": "read",
    "action_left_label": "Read",
    "action_right": "dismiss",
    "action_right_label": "Dismiss"
  }
}

RESULT:
  [Read] [Read Later] [Dismiss]

═══════════════════════════════════════════════════════════════
  THEY ARE IDENTICAL!
═══════════════════════════════════════════════════════════════

The ONLY difference is:
  - Highlights: "Watch" and "Watch Later"
  - News: "Read" and "Read Later"

Everything else works exactly the same way!

═══════════════════════════════════════════════════════════════
  BACKEND CONTROLS EVERYTHING
═══════════════════════════════════════════════════════════════

For BOTH types, backend can customize:
  ✓ Primary action label (action_left_label)
  ✓ Secondary action label (action_right_label)
  ✓ Image URL
  ✓ All content data
