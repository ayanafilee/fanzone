═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

NO NOTIFICATION?

Step 1: Check if received
  Look for: 📬 Foreground message received!
  
  If YES → Go to Step 2
  If NO → Problem: Not reaching app
    - Check topic subscription
    - Verify FCM token
    - Test with Firebase Console

Step 2: Check if displayed
  Look for: ✅ Local notification displayed successfully
  
  If YES → Should appear on device!
  If NO → Problem: Display issue
    - Check notification permissions
    - Try uninstall/reinstall

IMAGE NOT LOADING?
  Look for: ⚠️ Error loading notification image
  
  This is OK! Notification will still show without image.
  
  To fix:
    - Verify image URL is valid
    - Check URL uses HTTPS
    - Test URL in browser

  ACTION BUTTONS
═══════════════════════════════════════════════════════════════

App creates 3 buttons:
  1. Left (from backend) - Primary action
  2. Middle (automatic) - "Watch Later" or "Read Later"
  3. Right (from backend) - Secondary action

Example for highlights:
  [Watch] [Watch Later] [Dismiss]

Example for news:
  [Read] [Read Later] [Dismiss]
