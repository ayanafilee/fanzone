═══════════════════════════════════════════════════════════════
  HOW IT WORKS
═══════════════════════════════════════════════════════════════

1. User sees news card with preview
2. User sees "Read More" button
3. User taps anywhere on card OR taps button
4. Detail screen opens
5. User reads full article
6. User returns to feed
