# FanZone Landing Page

Modern, responsive landing page for the FanZone football fan engagement platform.

## Features

- Modern gradient design with dark theme
- Fully responsive layout
- Smooth scroll navigation
- Feature showcase section
- Download section with app store links
- Admin login link

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React (icons)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the landing page.

## Customization

- Update app store links in the Download section
- Modify colors in `tailwind.config.ts`
- Add more sections as needed
- Connect admin login to your dashboard

## Deployment

Deploy easily on Vercel:

```bash
npm install -g vercel
vercel
```

Or use any other hosting platform that supports Next.js.
