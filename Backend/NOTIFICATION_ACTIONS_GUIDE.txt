================================================================================
                    NOTIFICATION ACTION BUTTONS GUIDE
================================================================================

OVERVIEW:
The backend now sends action button metadata in the notification payload.
The mobile app needs to implement these actions to show buttons on notifications.

================================================================================
                         ACTION BUTTONS CONFIGURATION
================================================================================

-----------------------
Left Button: "Watch"
Right Button: "Dismiss"

When user taps "Watch":

- Play the video

When user taps "Dismiss":
- Dismiss the notification
- No further action


NEWS NOTIFICATIONS

Right Button: "Dismiss"

- Show the article

When user taps "Dismiss":
- Dismiss the notification
- No further action

================================================================================
                         DATA PAYLOAD FIELDS
================================================================================

ACTION FIELDS
-------------
action_left: "watch" or "read"
  - Identifier for the left action button
  - Used by mobile app to determine action

action_left_label: "Watch" or "Read"
  - Display text for the left button
  - Shown to user on notification

action_right: "dismiss"
  - Identifier for the right action button
  - Always "dismiss" for now

action_right_label: "Dismiss"
  - Display text for the right button
  - Shown to user on notification


ANDROID CONFIG FIELDS
----------------------
click_action: "FLUTTER_NOTIFICATION_CLICK"
  - Required for Flutter apps
  - Tells Android to route notification to app
  - Enables custom action handling

image_url: "https://..."
  - URL to notification image
  - Shows large preview in notification

FLUTTER EXAMPLE (flutter_local_notifications)
----------------------------------------------

1. SETUP NOTIFICATION ACTIONS
```dart
// Define notification actions
const AndroidNotificationAction watchAction = AndroidNotificationAction(
  'watch',
  'Watch',
  icon: DrawableResourceAndroidBitmap('ic_play'),
);

const AndroidNotificationAction readAction = AndroidNotificationAction(
  'read',
  'Read',
  icon: DrawableResourceAndroidBitmap('ic_read'),
);

const AndroidNotificationAction dismissAction = AndroidNotificationAction(
  'dismiss',
  'Dismiss',
  icon: DrawableResourceAndroidBitmap('ic_close'),
  cancelNotification: true,
);

// Create notification channel with actions
const AndroidNotificationChannel channel = AndroidNotificationChannel(
  'fanzone_notifications',
  'FanZone Notifications',
  description: 'Notifications for news and highlights',
  importance: Importance.high,
  actions: <AndroidNotificationAction>[
    watchAction,
    readAction,
    dismissAction,
  ],
);
```

2. SHOW NOTIFICATION WITH ACTIONS
```dart
Future<void> showNotificationWithActions(RemoteMessage message) async {
  final data = message.data;
  final type = data['type'];
  final imageUrl = data['image_url'];
  
  // Determine which actions to show
  List<AndroidNotificationAction> actions = [];
  
  if (type == 'highlight') {
    actions = [watchAction, dismissAction];
  } else if (type == 'news') {
    actions = [readAction, dismissAction];
  }
  
  // Download image
  final imagePath = await downloadImage(imageUrl);
  
  // Show notification
  await flutterLocalNotificationsPlugin.show(
    message.hashCode,
    message.notification?.title,
    message.notification?.body,
    NotificationDetails(
      android: AndroidNotificationDetails(
        'fanzone_notifications',
        'FanZone Notifications',
        channelDescription: 'Notifications for news and highlights',
        importance: Importance.high,
        priority: Priority.high,
        styleInformation: BigPictureStyleInformation(
          FilePathAndroidBitmap(imagePath),
          contentTitle: message.notification?.title,
          summaryText: message.notification?.body,
        ),
        actions: actions,
      ),
    ),
    payload: jsonEncode(data),
  );
}
```

3. HANDLE ACTION BUTTON TAPS
```dart
// Initialize notification plugin with action handler
final InitializationSettings initializationSettings = InitializationSettings(
  android: AndroidInitializationSettings('@mipmap/ic_launcher'),
);

await flutterLocalNotificationsPlugin.initialize(
  initializationSettings,
  onDidReceiveNotificationResponse: (NotificationResponse response) {
    final action = response.actionId;
    final payload = response.payload;
    
    if (payload != null) {
      final data = jsonDecode(payload);
      
      if (action == 'watch') {
        // Navigate to highlight detail
        navigateToHighlight(data['highlight_id']);
      } else if (action == 'read') {
        // Navigate to news detail
        navigateToNews(data['content_id']);
      } else if (action == 'dismiss') {
        // Just dismiss (handled automatically)
      } else {
        // Notification body tapped (no action button)
        handleNotificationTap(data);
      }
    }
  },
);
```

4. NAVIGATION HELPERS
```dart
void navigateToHighlight(String highlightId) {
  // Navigate to highlight detail screen
  Navigator.pushNamed(
    context,
    '/highlight-detail',
    arguments: {'id': highlightId},
  );
}

void navigateToNews(String contentId) {
  // Navigate to news detail screen
  Navigator.pushNamed(
    context,
    '/news-detail',
    arguments: {'id': contentId},
  );
}

void handleNotificationTap(Map<String, dynamic> data) {
  final type = data['type'];
  
  if (type == 'highlight') {
    navigateToHighlight(data['highlight_id']);
  } else if (type == 'news') {
    navigateToNews(data['content_id']);
  }
}
```

                         REACT NATIVE EXAMPLE
================================================================================

1. SETUP NOTIFICATION ACTIONS
```javascript
import notifee, { AndroidImportance } from '@notifee/react-native';

// Create notification channel with actions
await notifee.createChannel({
  id: 'fanzone_notifications',
  name: 'FanZone Notifications',
  importance: AndroidImportance.HIGH,
});

// Define actions
const watchAction = {
  title: 'Watch',
  pressAction: { id: 'watch' },
};

const readAction = {
  title: 'Read',
  pressAction: { id: 'read' },
};

const dismissAction = {
  title: 'Dismiss',
  pressAction: { id: 'dismiss' },
};
```

2. SHOW NOTIFICATION WITH ACTIONS
```javascript
async function showNotificationWithActions(remoteMessage) {
  const { data, notification } = remoteMessage;
  const type = data.type;
  const imageUrl = data.image_url;
  
  // Determine actions based on type
  const actions = type === 'highlight' 
    ? [watchAction, dismissAction]
    : [readAction, dismissAction];
  
  // Show notification
  await notifee.displayNotification({
    title: notification.title,
    body: notification.body,
    data: data,
    android: {
      channelId: 'fanzone_notifications',
      largeIcon: imageUrl,
      style: {
        type: AndroidStyle.BIGPICTURE,
        picture: imageUrl,
      },
      actions: actions,
      pressAction: {
        id: 'default',
      },
    },
  });
}
```

3. HANDLE ACTION BUTTON TAPS
```javascript
import { useEffect } from 'react';
import notifee, { EventType } from '@notifee/react-native';

useEffect(() => {
  return notifee.onForegroundEvent(({ type, detail }) => {
    if (type === EventType.ACTION_PRESS) {
      const { pressAction, notification } = detail;
      const data = notification.data;
      
      if (pressAction.id === 'watch') {
        // Navigate to highlight
        navigation.navigate('HighlightDetail', {
          id: data.highlight_id,
        });
      } else if (pressAction.id === 'read') {
        // Navigate to news
        navigation.navigate('NewsDetail', {
          id: data.content_id,
        });
      } else if (pressAction.id === 'dismiss') {
        // Just dismiss
        notifee.cancelNotification(notification.id);
      }
    }
  });
}, []);
```

================================================================================
                         TROUBLESHOOTING
================================================================================

ISSUE: Action buttons not showing
----------------------------------
Solutions:
1. Ensure mobile app implements action buttons
2. Check notification channel has actions configured
3. Verify Android version supports actions (Android 4.1+)
4. Check notification is expanded (swipe down)


ISSUE: Action buttons show but don't work
------------------------------------------
Solutions:
1. Verify action handler is registered
2. Check action IDs match (watch, read, dismiss)
3. Ensure navigation is properly configured
4. Check logs for action press events


ISSUE: Wrong actions showing
-----------------------------
Solutions:
1. Check notification type in data payload
2. Verify backend sends correct action_left value
3. Check mobile app action logic
4. Review server logs for action configuration

final leftLabel = data['action_left_label'] ?? 'Watch';

ADD MORE ACTIONS
----------------

Backend:

data["action_middle"] = "save"

const AndroidNotificationAction saveAction = AndroidNotificationAction(

================================================================================
                         BEST PRACTICES
================================================================================

1. KEEP ACTIONS SIMPLE
   - Maximum 3 actions per notification
   - Use clear, concise labels
   - Make primary action most prominent

2. CONSISTENT BEHAVIOR
   - Watch/Read should always open content
   - Dismiss should always close notification
   - Don't surprise users with unexpected actions

3. HANDLE OFFLINE
   - Check network before opening content
   - Show error if content unavailable
   - Cache content for offline viewing

4. TRACK ANALYTICS
   - Log which actions users tap
   - Measure engagement rates
   - Optimize based on user behavior

5. TEST THOROUGHLY
   - Test on different Android versions
   - Test with app in foreground/background
   - Test with different notification states
