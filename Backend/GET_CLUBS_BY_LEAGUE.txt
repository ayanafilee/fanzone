================================================================================
                    GET CLUBS BY LEAGUE ENDPOINT DOCUMENTATION
================================================================================

ENDPOINT: GET /api/leagues/:id/clubs

DESCRIPTION:
Returns all clubs that belong to a specific league. This is a public endpoint
that doesn't require authentication.

AUTHENTICATION: NOT REQUIRED (Public)

================================================================================
                              REQUEST
================================================================================

URL:
GET http://your-server:8080/api/leagues/:id/clubs

URL Parameters:
:id - League ID (MongoDB ObjectID, 24-character hex string)

Request Headers:
Content-Type: application/json

Request Body: None

Response Fields:
- league_id: The ID of the league (same as request parameter)
- clubs: Array of club objects belonging to this league
- total_clubs: Number of clubs in this league

Club Object Structure:
{
  "id": "string (MongoDB ObjectID)",
  "name": "string",
  "logo_url": "string (URL)",
  "league_id": "string (MongoDB ObjectID)"
}

Error Responses:

400 Bad Request (Invalid league ID):
{
  "error": "Invalid league ID"
}

404 Not Found (League doesn't exist):
{
  "error": "League not found"
}

500 Internal Server Error:
{
  "error": "Error fetching clubs"
}

Example 5: React Component
---------------------------
import React, { useState, useEffect } from 'react';

function LeagueClubs({ leagueId }) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch(`http://localhost:8080/api/leagues/${leagueId}/clubs`)
      .then(res => res.json())
      .then(data => {
        setData(data);
        setLoading(false);
      });
  }, [leagueId]);

  if (loading) return <div>Loading...</div>;

  return (
    <div>
      <h2>Clubs ({data.total_clubs})</h2>
      <ul>
        {data.clubs.map(club => (
          <li key={club.id}>
            <img src={club.logo_url} alt={club.name} width="30" />
            {club.name}
          </li>
        ))}
      </ul>
    </div>
  );
}


Example 6: Flutter
------------------
import 'package:http/http.dart' as http;
import 'dart:convert';

Future<Map<String, dynamic>> getClubsByLeague(String leagueId) async {
  final response = await http.get(
    Uri.parse('http://localhost:8080/api/leagues/$leagueId/clubs')
  );
  
  if (response.statusCode == 200) {
    return jsonDecode(response.body);
  } else {
    throw Exception('Failed to load clubs');
  }
}

// Usage
void main() async {
  final data = await getClubsByLeague('507f1f77bcf86cd799439011');
  print('Total clubs: ${data['total_clubs']}');
  
  for (var club in data['clubs']) {
    print('- ${club['name']}');
  }
}

================================================================================
                         COMPARISON WITH OTHER ENDPOINTS
================================================================================

GET /api/clubs
- Returns ALL clubs from ALL leagues
- No filtering
- Use when you want complete club list

GET /api/leagues/:id/clubs
- Returns clubs from SPECIFIC league only
- Filtered by league
- Use when you want clubs grouped by league
- Includes total count

GET /api/clubs/:id
- Returns SINGLE club details
- Use when you need specific club information

================================================================================
                         PERFORMANCE NOTES
================================================================================

1. Response Size:
   - Small leagues: ~5-10 clubs
   - Large leagues: ~20 clubs
   - Response is lightweight and fast

2. Caching Recommendations:
   - Cache response for 5-10 minutes
   - Clubs rarely change leagues
   - Refresh when user pulls to refresh

3. Optimization:
   - Consider pagination for very large leagues (100+ clubs)
   - Current implementation loads all clubs at once
   - Suitable for typical football leagues (20-30 clubs max)

================================================================================
                         ERROR HANDLING
================================================================================

Handle these scenarios in your app:

1. Invalid League ID
   - Show error: "Invalid league selected"
   - Redirect back to leagues list

2. League Not Found
   - Show error: "League not found"
   - Might have been deleted by admin

3. No Clubs in League
   - Response: { "clubs": [], "total_clubs": 0 }
   - Show message: "No clubs in this league yet"

4. Network Error
   - Show error: "Unable to load clubs"
   - Provide retry button

Example Error Handling (JavaScript):
try {
  const response = await fetch(`/api/leagues/${leagueId}/clubs`);
  
  if (!response.ok) {
    if (response.status === 404) {
      alert('League not found');
    } else if (response.status === 400) {
      alert('Invalid league ID');
    } else {
      alert('Error loading clubs');
    }
    return;
  }
  
  const data = await response.json();
  
  if (data.total_clubs === 0) {
    showMessage('No clubs in this league yet');
  } else {
    displayClubs(data.clubs);
  }
} catch (error) {
  alert('Network error. Please try again.');
}
