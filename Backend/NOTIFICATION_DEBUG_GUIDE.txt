================================================================================
                    PUSH NOTIFICATION DEBUGGING GUIDE
================================================================================

OVERVIEW:
Detailed console logging has been added to help debug push notification issues.
All logs use emoji prefixes for easy identification.

================================================================================
                         LOG PREFIXES EXPLAINED
================================================================================

🔧 [FCM INIT]           - Firebase initialization
✅ [FCM INIT]           - Successful initialization
❌ [FCM INIT ERROR]     - Initialization failed

📤 [FCM SEND]           - Preparing to send to topic
📤 [FCM DEVICE]         - Preparing to send to device
📤 [FCM MULTICAST]      - Preparing to send to multiple devices

🚀 [FCM SEND]           - Sending message to Firebase
✅ [FCM SUCCESS]        - Message sent successfully
❌ [FCM ERROR]          - Failed to send message
📬 [FCM RESPONSE]       - Firebase response details

🔔 [NOTIFY CONTENT]     - Content notification triggered
🔔 [NOTIFY HIGHLIGHT]   - Highlight notification triggered
🔔 [NOTIFY ALL]         - Broadcast notification triggered

🔔 [ADMIN]              - Admin action triggering notification
🏟️  [ADMIN]             - Club information
📝 [ADMIN]              - Content details
🎥 [ADMIN]              - Highlight details
🚀 [ADMIN]              - Starting background notification
⚠️  [ADMIN]             - Warning or skipped action
❌ [ADMIN]              - Error in admin handler

🔔 [ADMIN GOROUTINE]    - Background notification process
✅ [ADMIN GOROUTINE]    - Background process successful
❌ [ADMIN GOROUTINE ERROR] - Background process failed

================================================================================
                         COMMON ISSUES & SOLUTIONS
================================================================================

ISSUE 1: No logs appear at all
-------------------------------
Problem: Server not logging anything
Solution:
- Check if server is running
- Verify you're looking at the correct log output
- Check if logging is disabled


ISSUE 2: FCM initialization fails
----------------------------------
Logs show:
❌ [FCM INIT ERROR] Failed to initialize Firebase app

Solutions:
1. Check service account file exists:
   - Path: internal/config/fanzone-c7f93-firebase-adminsdk-fbsvc-7fa1955ab1.json
   - Verify file is present
   - Check file permissions

2. Verify JSON file is valid:
   - Open file and check it's valid JSON
   - Ensure it contains project_id, private_key, client_email

3. Check Firebase project settings:
   - Verify project ID matches
   - Ensure service account has correct permissions


ISSUE 3: Notification triggered but not sent
---------------------------------------------
Logs show:
🔔 [ADMIN] Content created, checking notification requirements...
⚠️  [ADMIN] No club specified for content, skipping notification

Solution:
- Ensure you're providing club_id when creating content
- Club ID must be valid MongoDB ObjectID


ISSUE 4: FCM service is nil
----------------------------
Logs show:
❌ [ADMIN] FCM service is nil, cannot send notification

Solution:
- Check server startup logs for FCM initialization
- Ensure FCM initialized successfully on startup
- Restart server if needed


ISSUE 5: Club not found
------------------------
Logs show:
❌ [ADMIN] Failed to find club: mongo: no documents in result

Solution:
- Verify club exists in database
- Check club ID is correct
- Use GET /api/clubs to list available clubs


ISSUE 6: Message sent but not received on mobile
-------------------------------------------------
Logs show:
✅ [FCM SUCCESS] Message sent successfully
📬 [FCM RESPONSE] Firebase response: projects/fanzone-c7f93/messages/1234567890

But mobile doesn't receive notification.

Solutions:
1. Check mobile app is subscribed to topic:
   - Topic format: club_507f1f77bcf86cd799439011
   - Verify subscription in mobile app code

2. Check Firebase Console:
   - Go to Firebase Console > Cloud Messaging
   - Check message delivery status
   - Look for errors or failures

3. Check mobile app permissions:
   - Ensure notification permissions granted
   - Check app is in foreground/background
   - Verify FCM token is valid

4. Check topic name:
   - Logs show: "Sending to topic: club_507f1f77bcf86cd799439011"
   - Mobile must subscribe to exact same topic name
   - Topic names are case-sensitive

5. Test with Firebase Console:
   - Send test notification from Firebase Console
   - If test works, issue is in backend
   - If test fails, issue is in mobile app


ISSUE 7: Multicast failures
----------------------------
Logs show:
⚠️  [FCM MULTICAST] 3 failures
❌ [FCM MULTICAST FAILURE] Token 0 failed: registration token is invalid

Solution:
- Invalid or expired device tokens
- Remove invalid tokens from database
- Implement token refresh mechanism


ISSUE 8: Firebase quota exceeded
---------------------------------
Logs show:
❌ [FCM ERROR] Failed to send message: quota exceeded

Solution:
- Check Firebase usage limits
- Upgrade Firebase plan if needed
- Reduce notification frequency

================================================================================
                         LOG ANALYSIS TIPS
================================================================================

1. Use grep to filter logs:
   grep "FCM" server.log
   grep "NOTIFY" server.log
   grep "ERROR" server.log

2. Follow logs in real-time:
   tail -f server.log | grep "FCM\|NOTIFY"

3. Count successful notifications:
   grep "FCM SUCCESS" server.log | wc -l

4. Find errors:
   grep "ERROR" server.log

5. Check specific club notifications:
   grep "club_507f1f77bcf86cd799439011" server.log
