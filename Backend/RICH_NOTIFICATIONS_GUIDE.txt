================================================================================
                    RICH NOTIFICATIONS IMPLEMENTATION GUIDE
================================================================================

OVERVIEW:
The backend now supports YouTube-style rich notifications with:
- Large preview images (expandable)
- YouTube thumbnail auto-generation
- Android-specific image configuration
- Enhanced data payload for mobile app

================================================================================
                         WHAT WAS IMPLEMENTED
================================================================================

1. AUTOMATIC YOUTUBE THUMBNAIL GENERATION
   - Extracts video ID from YouTube URLs
   - Generates high-quality thumbnail URLs
   - Supports multiple YouTube URL formats

2. ANDROID-SPECIFIC IMAGE CONFIGURATION
   - Adds image to notification.android.image
   - Enables system-level rich notifications
   - Works in background/terminated states

3. ENHANCED DATA PAYLOAD
   - Includes image_url in data
   - Includes video_url for highlights
   - Includes title for news

4. DETAILED LOGGING
   - Logs image URLs being sent
   - Logs thumbnail generation
   - Helps debug notification issues

================================================================================
                         YOUTUBE THUMBNAIL GENERATION
================================================================================

SUPPORTED URL FORMATS
---------------------
The system automatically extracts video ID from:

1. Standard watch URL:
   https://youtube.com/watch?v=dQw4w9WgXcQ
   → Video ID: dQw4w9WgXcQ

2. Short URL:
   https://youtu.be/dQw4w9WgXcQ
   → Video ID: dQw4w9WgXcQ

3. Embed URL:
   https://youtube.com/embed/dQw4w9WgXcQ
   → Video ID: dQw4w9WgXcQ

4. Direct video URL:
   https://youtube.com/v/dQw4w9WgXcQ
   → Video ID: dQw4w9WgXcQ


THUMBNAIL QUALITY
-----------------
Generated thumbnail URL format:
https://img.youtube.com/vi/VIDEO_ID/maxresdefault.jpg

Quality: 1280x720 (16:9 aspect ratio)
Format: JPG
Size: ~100-300KB

Alternative qualities available:
- hqdefault.jpg (480x360)
- sddefault.jpg (640x480)
- mqdefault.jpg (320x180)

================================================================================
                         HOW IT WORKS
================================================================================

WHEN ADMIN CREATES NEWS
------------------------
1. Admin creates content via POST /api/admin/content
2. Request includes:
   - title (multilingual)
   - body (multilingual)
   - image_url (news image)
   - club_id

3. Backend processes:
   - Saves content to database
   - Logs notification trigger
   - Finds club information
   - Starts background goroutine

4. Notification sent with:
   - Title: "New news from {club_name}"
   - Body: {title in English}
   - Android image: {image_url}
   - Data includes: image_url, title, club info

5. Mobile app receives:
   - Foreground: Custom notification with image
   - Background: System notification with image
   - Action buttons: Read, Read Later, Turn Off


WHEN ADMIN CREATES HIGHLIGHT
-----------------------------
1. Admin creates highlight via POST /api/admin/highlights
2. Request includes:
   - match_title
   - youtube_url
   - club_ids (array)

3. Backend processes:
   - Saves highlight to database
   - Extracts YouTube video ID
   - Generates thumbnail URL
   - Logs thumbnail generation
   - Finds club information for each club
   - Starts background goroutine

4. For each club:
   - Sends notification to club topic
   - Title: "New Match Highlight"
   - Body: {match_title}
   - Android image: {youtube_thumbnail}
   - Data includes: video_url, image_url, match_title

5. Mobile app receives:
   - Foreground: Custom notification with YouTube thumbnail
   - Background: System notification with thumbnail
   - Action buttons: Watch, Watch Later, Turn Off

================================================================================
                         MOBILE APP BEHAVIOR
================================================================================

FOREGROUND (APP OPEN)
----------------------
1. Notification received via onMessage
2. App downloads image from image_url
3. Shows custom local notification with:
   - Large image preview
   - Action buttons (Watch/Read, Watch Later/Read Later, Turn Off)
   - Custom styling

Expected logs:
📬 Foreground message received!
📬 Title: New Match Highlight
📬 Body: NEWCASTLE 2-3 EVERTON
📬 Data: {type: highlight, image_url: https://...}
📸 Loading notification image: https://...
✅ Image loaded successfully
🔔 Showing local notification: New Match Highlight
✅ Local notification displayed successfully


BACKGROUND/TERMINATED (APP CLOSED)
-----------------------------------
1. Notification received by system
2. Android uses notification.android.image
3. Shows system notification with:
   - Large image preview (expandable)
   - Default system styling
   - Tap to open app

User sees:
- Collapsed: Small icon + title + body
- Expanded: Large image + title + body
- Tap: Opens app to content

================================================================================
                         TROUBLESHOOTING
================================================================================

ISSUE: No image in notification
--------------------------------
Check logs for:
🖼️  [FCM SEND] Adding image to notification: ...

If missing:
- Verify image_url is provided in content
- Check image URL is valid and accessible
- Ensure image is HTTPS (not HTTP)


ISSUE: YouTube thumbnail not generated
---------------------------------------
Check logs for:
⚠️  [NOTIFY HIGHLIGHT] Could not generate thumbnail from video URL

Solutions:
- Verify YouTube URL format is correct
- Check URL contains valid video ID
- Test URL in browser


ISSUE: Image loads slowly
--------------------------
Solutions:
- Use smaller images (max 1MB)
- Optimize images before uploading
- Use CDN for faster delivery
- Consider using YouTube's default quality (hqdefault.jpg)


ISSUE: Image not showing on Android
------------------------------------
Check:
- Image URL is HTTPS (required by Android)
- Image is publicly accessible
- Image format is JPG or PNG
- Image size is reasonable (<1MB)
- Firebase project has correct configuration

================================================================================
                         IMAGE REQUIREMENTS
================================================================================

NEWS IMAGES
-----------
- Format: JPG or PNG
- Recommended size: 1280x720 (16:9 aspect ratio)
- Max file size: 1MB
- Must be publicly accessible (HTTPS)
- Should be optimized for web

YOUTUBE THUMBNAILS
------------------
- Auto-generated from video URL
- Format: JPG
- Size: 1280x720 (maxresdefault)
- Hosted by YouTube (always accessible)
- No optimization needed

GENERAL GUIDELINES
------------------
- Use high-quality images
- Maintain 16:9 aspect ratio
- Compress images before uploading
- Use CDN for better performance
- Test images load on mobile devices
