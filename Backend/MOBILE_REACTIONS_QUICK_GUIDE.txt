================================================================================
                    REACTIONS - QUICK GUIDE FOR MOBILE TEAM
================================================================================

## What Are Reactions?
Users can react to news and highlights with 5 emoji reactions:
👍 like | ❤️ love | 😮 wow | 😢 sad | 😠 angry

## How It Works
Reactions are ANONYMOUS - no user tracking needed!
Just tap a reaction button and the count increases.

================================================================================
                              API ENDPOINTS
================================================================================

BASE URL: https://your-api.com/api

All endpoints are PUBLIC (no authentication needed)

--------------------------------------------------------------------------------
1. ADD REACTION (Increment Count)
--------------------------------------------------------------------------------
POST /api/reactions

Request Body:
{
  "content_type": "news",
  "content_id": "507f1f77bcf86cd799439012",
  "reaction_type": "like"
}

Fields:
- content_type: "news" or "highlight" (required)
- content_id: ID of the news/highlight (required)
- reaction_type: "like", "love", "wow", "sad", or "angry" (required)

Response (200 OK):
{
  "success": true,
  "message": "Reaction added",
  "reaction": {
    "content_type": "news",
    "content_id": "507f1f77bcf86cd799439012",
    "reaction_type": "like"
  },
  "counts": {
    "like": 46,
    "love": 23,
    "wow": 12,
    "sad": 3,
    "angry": 1
  }
}

When to use:
- User taps any reaction button
- Each tap increments that reaction count by 1

--------------------------------------------------------------------------------
2. GET REACTION COUNTS
--------------------------------------------------------------------------------
GET /api/reactions/:content_type/:content_id/counts

Example:
GET /api/reactions/news/507f1f77bcf86cd799439012/counts

Response (200 OK):
{
  "content_type": "news",
  "content_id": "507f1f77bcf86cd799439012",
  "counts": {
    "like": 45,
    "love": 23,
    "wow": 12,
    "sad": 3,
    "angry": 1
  },
  "total": 84
}

When to use:
- When loading a news/highlight detail page
- To display current reaction counts

## Simple React Native Component
```javascript
import React, { useState, useEffect } from 'react';
import { View, TouchableOpacity, Text } from 'react-native';

const ReactionBar = ({ contentType, contentId }) => {
  const [counts, setCounts] = useState({
    like: 0, love: 0, wow: 0, sad: 0, angry: 0
  });

  const reactions = [
    { type: 'like', emoji: '👍' },
    { type: 'love', emoji: '❤️' },
    { type: 'wow', emoji: '😮' },
    { type: 'sad', emoji: '😢' },
    { type: 'angry', emoji: '😠' }
  ];

  useEffect(() => {
    loadCounts();
  }, []);

  const loadCounts = async () => {
    try {
      const response = await fetch(
        `https://your-api.com/api/reactions/${contentType}/${contentId}/counts`
      );
      const data = await response.json();
      setCounts(data.counts);
    } catch (error) {
      console.error('Failed to load counts:', error);
    }
  };

  const handleReaction = async (reactionType) => {
    // Optimistic update
    setCounts(prev => ({ 
      ...prev, 
      [reactionType]: prev[reactionType] + 1 
    }));

    // Sync with backend
    try {
      const response = await fetch('https://your-api.com/api/reactions', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          content_type: contentType,
          content_id: contentId,
          reaction_type: reactionType
        })
      });
      
      const data = await response.json();
      // Update with actual counts from server
      setCounts(data.counts);
    } catch (error) {
      // Revert on error
      setCounts(prev => ({ 
        ...prev, 
        [reactionType]: prev[reactionType] - 1 
      }));
      alert('Failed to add reaction');
    }
  };

  return (
    <View style={{ flexDirection: 'row', gap: 10, padding: 10 }}>
      {reactions.map(({ type, emoji }) => (
        <TouchableOpacity
          key={type}
          onPress={() => handleReaction(type)}
          style={{
            padding: 8,
            borderRadius: 20,
            backgroundColor: '#f5f5f5'
          }}
        >
          <Text style={{ fontSize: 16 }}>
            {emoji} {counts[type]}
          </Text>
        </TouchableOpacity>
      ))}
    </View>
  );
};

export default ReactionBar;
```

## Use in Your Screen
```javascript
import ReactionBar from './components/ReactionBar';

const NewsDetailScreen = ({ route }) => {
  const { newsId } = route.params;

  return (
    <View>
      <Text>News Title</Text>
      <Text>News Body</Text>
      
      {/* Add reaction bar */}
      <ReactionBar contentType="news" contentId={newsId} />
    </View>

```

================================================================================
                              USER FLOW
================================================================================

Simple Flow:
1. User opens news/highlight
2. App loads and displays reaction counts
3. User taps "like" button
4. Count increases immediately (optimistic update)
5. App sends POST request to backend
6. Backend increments count in database
7. App updates with actual count from server

Note: Users can tap multiple times, each tap adds +1 to that reaction.

================================================================================
                              COMMON ERRORS
================================================================================

400 Bad Request:
- Missing required field (content_type, content_id, reaction_type)
- Invalid content_type (must be "news" or "highlight")
- Invalid reaction_type (must be like, love, wow, sad, or angry)
- Invalid ID format (must be 24-character hex string)

404 Not Found:
- Content doesn't exist

500 Internal Server Error:
- Database error
- Contact backend team

================================================================================
                              TIPS
================================================================================

✅ DO:
- Use optimistic UI updates (update UI immediately, sync with backend)
- Show loading state while syncing
- Handle errors gracefully
- Debounce rapid taps if needed

❌ DON'T:
- Don't make API calls on every render
- Don't forget to handle offline mode
- Don't show technical errors to users
